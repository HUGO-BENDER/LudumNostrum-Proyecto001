# Glosario

| Término | Significado |
|---|---|
| Issue | Unidad de trabajo pequeña (S/M) con criterios de aceptación verificables |
| ADR | Architecture Decision Record: decisión registrada en `decisions/` |
| StepNNN | Nombre que usa el usuario para cada paso del proyecto; se corresponde con un issue (p. ej. Step001 = issue 0001) |
